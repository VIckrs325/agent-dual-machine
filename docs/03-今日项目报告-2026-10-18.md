## 五、关键发现（与原计划的偏差）

1. **算力端地址不是 .125**：.125 是另一台已离线的 Windows 机；真机是 `.136`。
2. **内存 32GB 而非 16GB** → 长上下文余量比预期大一倍，OOM 风险显著下降（可放宽到 8k 上下文）。
3. **用户已提前完成 OpenClaw 安装与 DeepSeek 鉴权**，阶段一不是从零开始。
4. **Ollama 已有 3 个 7B 变体**，阶段二模型侧提前完成。
5. **但 Ollama 未注册进 OpenClaw**：`openclaw.json` 里没有 ollama provider → 混合调度实际未生效。
6. **DSH 未接入**：`~/.dsh` 有凭据目录，但 `openclaw.json` 的 plugins 只有 anthropic/codex/deepseek，且全局 npm 只装了 openclaw。
7. **默认模型指向 fallback**：`agents.defaults.model = deepseek/deepseek-flash`，而官方 default 标签是 `deepseek-v4-pro` —— 建议确认是否有意（flash 更便宜但能力弱）。
8. **Ollama 只监听 127.0.0.1** → OpenClaw 必须与其同机（当前就是），本机无法直连。
