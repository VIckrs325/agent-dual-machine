# 16 — 怎么问才会触发搜索（以及哪些问法真能搜到东西）

> 2026-10-19 · 全部数据来自 2060 实机跑 `search.mjs`，不是推测。

## 0. 一句话结论

**问法的影响比你想的大得多。**

同一个问题，用自然语言问句经常**一条可用结果都拿不到**，换成干净的关键词能拿 3 条：

| 你问 | 实际检索词 | 可用结果 |
| --- | --- | --- |
| 周杰伦是谁 | `周杰伦是谁` | **0 条** |
| 周杰伦 | `周杰伦` | **3 条**（百度百科 / 维基） |
| 现在美元汇率多少 | `现在美元汇率` | **0 条** |
| 美元汇率 | `美元汇率` | **3 条**（新浪财经 / 实时汇率网） |
| 帮我查 SpaceX 星舰最新进展 | `帮我查 SpaceX…` | **0 条** |
| SpaceX 星舰最新进展 | `SpaceX 星舰最新进展` | **2 条**（SpaceX 官网 / 维基） |

我已经把「剥掉问句外壳」做进了 `buildQuery()`（`search.mjs`），所以上面三组现在都能自动救回来。**但你自己问得简洁，命中率会更高、也更快。**

---

## 1. 触发规则：什么样的问法会被判定"该搜"

桥里是**代码判断**，不是模型决定。三档：

| 档 | 触发条件 | 超时 | 结果处理 |
| --- | --- | --- | --- |
| **force** | ① 显式指令：`搜一下 / 查一下 / 帮我查 / 搜索 / 网上查` ② 时效词 + 疑问词同时出现 | 6s | 直接注入 |
| **attempt** | 时效词 或 实体查询词（`是谁 / 什么公司 / 多少钱 / 多久 / 什么时候 / 排名 / 创始人`） | 3.5s | **过质量门槛才注入**，不过就当没搜 |
| **skip** | 代码/报错类、闲聊、无信号短句 | 0 | 不搜 |

**时效词表**：最新 / 今天 / 昨天 / 明天 / 本周 / 最近 / 现在 / 当前 / 实时 / 新闻 / 价格 / 股价 / 汇率 / 天气 / 气温 / 降水 / 发布会 / 赛程 / 上映 / 比分 / 谁赢 / 多少钱 / 几年 / 多高 / 多大

**疑问词表**：吗 / 呢 / 多少 / 几 / 什么 / 怎么 / 如何 / 哪 / 谁 / 是否 / 有没有 / 支持 / 区别 / 多久 / 多长 / 多大 / 多高 / 什么时候 / 是不是 / 能不能

**豁免（一律不搜）**：含 `代码 / 函数 / 报错 / 异常 / 怎么改 / bug / python / javascript / sql / 正则`

## 2. 实测：15 条典型问法

| 问法 | 判定 | 可用结果 | 备注 |
| --- | --- | --- | --- |
| 你好 | skip | — | 闲聊不搜 |
| 讲个笑话 | skip | — | |
| 什么是 API | skip | — | 定义题本地就能答，省 2 秒 |
| Python 怎么反转列表 | skip(code) | — | 代码题豁免 |
| 这段报错怎么改 | skip(code) | — | |
| 五排满了怎么办 | skip | — | 无信号 |
| 今天北京天气 | attempt | 2 条（天气预报站）| 内容里没有具体气温 |
| 周杰伦是谁 | attempt | 0 → **改后 3** | 见第 0 节 |
| DeepSeek 是什么公司 | attempt | 2 条（官网）| |
| 论文答辩一般多久 | attempt | 0 | 这类"经验型"问题网上没有权威答案 |
| 现在美元汇率多少 | force | 0 → **改后 3** | |
| 最近有什么AI新闻 | force | 0~1 条 | **波动大**，见第 4 节 |
| iPhone 17 多少钱 | force | 2 条（Apple / 维基）| |
| Qwen3 什么时候发布的 | force | 3 条（官方博客 / GitHub / HF）| 最稳的一类 |
| 帮我查 SpaceX 星舰最新进展 | force | 0 → **改后 2** | |

**统计**：15 条里 skip 6 / attempt 4 / force 5；**改后可用率从 6/9 提升到 9/9**。

## 3. 照着抄：推荐的问法

### ✅ 最稳（几乎每次都能拿到可用结果）

| 场景 | 怎么问 |
| --- | --- |
| 技术/产品事实 | `Qwen3 什么时候发布的`、`iPhone 17 多少钱`、`DeepSeek 是什么公司` |
| 带明确主体的查询 | `周杰伦`、`SpaceX 星舰最新进展`、`iPhone 17` |
| 金融数据 | `美元汇率`、`美元兑人民币汇率`、`茅台股价` |
| 版本/发布日期 | `Python 3.13 发布时间`、`Ubuntu 24.04 支持多久` |

### ⚠️ 能触发但结果看运气

| 场景 | 说明 |
| --- | --- |
| 新闻类 | `最近有什么AI新闻` —— Bing 常给聚合站（今日热榜），摘要里没有具体事件 |
| 天气 | 能拿到天气预报站，但**摘要里没有温度数值**（表格抓不出） |
| 人物百科 | 只给名字最稳；`XX 个人资料` 反而更差 |

### ❌ 别指望搜索的问题

| 类型 | 例子 | 为什么会失败 |
| --- | --- | --- |
| 实时数值 | `北京现在几度`、`茅台现在多少钱` | 数值在 JS 渲染的表格里，摘要没有 |
| 主观/经验 | `论文答辩一般多久`、`五排满了怎么办` | 网上没有权威单一答案 |
| 代码调试 | `这段报错怎么改` | 代码题被豁免，且搜索只会给噪音 |
| 纯计算/推理 | `1234×5678`、`这段逻辑哪里错` | 本地模型更合适 |

## 4. 为什么新闻类波动大

同一句 `最近有什么AI新闻`，三次跑分别拿到 0 条 / 1 条（今日热榜）/ 3 条（OpenAI、Gemini、维基）。

原因：Bing 对"新闻"这类查询给的是**聚合页**，其摘要字段时有时无；我们的门槛（摘要 ≥50 字 + 相关性命中）会随摘要长度抖动。

**这不是 bug，是免费源的固有下限。** 要稳定只能上付费源（Bocha / Tavily）或新闻 API。

## 5. 你可以在 QQ 里这样验证

发完问题后看日志（`journalctl --user -u qq-bridge -f` 或 `~/qq-bridge.log`）：

```
[search] skip(no_signal) "你好"                       ← 没搜，以及原因
[llm+search] force/fresh+ask bing 1971ms raw=3 kept=3 q="北京今天天气"
                    ↑档位/原因      ↑原始3条  ↑过滤后3条 ↑真正发出去的检索词
[search] 未注入 reason=low quality q="..."            ← 搜了但结果不合格，没喂给模型
```

- 看 `q="..."`：这是实际检索词。**结果不对时先看它**。
- 看 `kept=`：0 就是被质量门槛拦了（宁可不用也不污染上下文）。
- 看 `mode/reason`：`skip(no_signal)` 说明你的话没被判成"需要搜索的问题"。

## 6. 想让某类问题**一定**搜？

加一句显式指令即可（会走 force 档，6s 超时）：

```
帮我查 <关键词>
搜一下 <关键词>
查一下 <关键词> 最新进展
```

但注意：显式指令不会提高结果质量，只保证"真的去搜了"。**关键词还是越干净越好。**

## 7. 一页速查

| 你要问的 | 推荐写法 | 避免 |
| --- | --- | --- |
| 某人是谁 | `周杰伦` | `周杰伦是谁` |
| 某公司做什么 | `DeepSeek` | `DeepSeek 是什么公司` |
| 汇率 | `美元汇率` / `美元兑人民币汇率` | `现在美元汇率多少` |
| 产品价格 | `iPhone 17 价格` | `iPhone 17 多少钱呀` |
| 发布时间 | `Qwen3 发布` | `Qwen3 是什么时候发布的呢` |
| 最新进展 | `SpaceX 星舰 发射` | `帮我查一下SpaceX最近怎么样了` |
| 天气 | `北京 天气`（知道拿不到数值） | `北京今天几度` |

**核心规律：名词 + 限定词；不要疑问句外壳。**
