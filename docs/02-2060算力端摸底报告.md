**待补齐（按优先级）**
1. `sudo apt install -y python3-pip`（部分工具链依赖）。
2. SSH 免密已打通（authorized_keys 已写入本机公钥）✅
3. 若要 OpenClaw 的 Docker 沙箱：安装 Docker + 将 `user` 加入 docker 组。
4. 建议把模型目录指到外接 1.9T 盘（`OLLAMA_MODELS=/media/user/.../ollama`），避免系统盘 57G 被吃满。
5. 路由器绑定 IP/MAC，避免 DHCP 换址导致 SSH 断联。

## 9. Ollama 网络绑定（架构选择）

实测 `Ollama` 只监听 **`127.0.0.1:11434`**，本机（Windows）**连不上** `.136:11434`（已测：closed）。这决定了两种部署形态：

| 方案 | 做法 | 适用 |
| --- | --- | --- |
| **A（推荐，符合原计划）** | OpenClaw 装在 2060 本，与 Ollama 同机，走 `127.0.0.1` | 零暴露、最稳定；本机只做 SSH 控制 |
| B | 让本机也能调本地模型 | 需改 `OLLAMA_HOST=0.0.0.0:11434` + systemd 覆盖 + 防火墙放行；仅限可信内网，有暴露风险 |

> 默认走 A。若以后想让 Windows 上的工具直连本地模型，再切 B。
