# 测试用例 02：多轮工具调用

**目标**：验证多轮工具调用可完整执行 ≥ 5 轮不中断

**提示词**：

```
请在 /tmp/agent-demo 目录下完成以下连续操作，每步都要实际执行命令验证结果：
1. 创建目录并进入
2. 用 curl 下载 https://example.com 首页保存为 index.html
3. 统计 index.html 的行数、字节数
4. 用 grep 找出所有 <title> 标签内容
5. 把上述统计结果追加写入 summary.txt
最后用一句话总结每一步的结果是否成功。
```

**验收要点**：
- [ ] 连续执行 ≥ 5 个独立工具调用且中途不中断
- [ ] 每步都有命令执行结果反馈，非空想
- [ ] `summary.txt` 内容与实际结果一致

**记录项**：总轮数、是否有轮次超时/重试、Token 消耗。
