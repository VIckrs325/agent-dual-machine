# 测试用例 03：完整 DSH 工程任务

**目标**：验证 DSH 沙箱能完整跑通一个端到端工程任务

**提示词**：

```
在沙箱工作区里从零搭一个最小可运行的 Web 服务：
1. 用 npm 初始化项目，安装 express 依赖
2. 写 server.js，提供 GET /health 返回 {"ok":true}
3. 启动服务并 curl 验证 /health 返回 200
4. 把「如何启动」写进 README.md
整个过程所有文件都落在沙箱工作区内，不要动沙箱外的路径。
```

**验收要点**：
- [ ] 沙箱内完成 npm install 且无权限报错
- [ ] 服务真实启动，`/health` 返回 200
- [ ] 产出文件均在沙箱 workspaceRoot 内
- [ ] 全程不越界访问沙箱外路径

**记录项**：DSH 单轮耗时（turnTimeoutMs 是否触发）、是否有授权拒绝、整体成功率。
