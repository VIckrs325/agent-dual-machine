# 测试用例 01：单步代码生成

**目标**：验证云端 DeepSeek 单步代码生成成功率 ≥ 90%

**提示词**：

```
写一个 Python 脚本，读取同目录下的 data.json 文件，
统计每个字段（key）在文件里出现的总次数，并把结果按次数从高到低写入 result.json。
要求：健壮处理文件不存在的情况，代码含中文注释。
```

**验收要点**：
- [ ] 一次生成即语法正确（无需二次修正）
- [ ] 能正确处理 `data.json` 缺失场景
- [ ] 输出 `result.json` 格式正确、排序正确

**记录项**：耗时、Token 消耗、是否一次通过。
